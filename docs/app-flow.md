## Actors

- Miembro de la familia — guarda los enlaces de las listas de la casa y las usa a diario.
- Persona ocasional — recibe el enlace de una lista concreta para ayudar con una compra puntual.

No hay distinción técnica entre ambos: el acceso es siempre por el enlace de la lista, y quien lo tiene puede hacerlo todo sobre ella.

## Main journey: Crear una lista

El miembro de la familia crea una lista con nombre para juntar lo que falta comprar.

```text
Enviar nombre → [¿nombre válido?] —no→ error de validación
                       │ sí
                       ▼
        Lista creada + enlace público → Abrir enlace → Ver lista → Enlace recordado en "Mis listas"
```

| Step | Actor                 | Action                            | Result                                                                    |
| ---- | --------------------- | --------------------------------- | ------------------------------------------------------------------------- |
| 1    | Miembro de la familia | Envía el nombre de la nueva lista | El sistema crea la lista con un enlace único y devuelve el enlace público |
| 2    | Miembro de la familia | Abre el enlace de la lista        | El sistema muestra la lista con sus ítems no comprados y comprados        |
| 3    | Miembro de la familia | Abre la lista                     | El navegador recuerda el enlace como acceso directo en "Mis listas"       |

```text
                                                                │ sí
                                                                ▼
                                          Ítem "no comprado" → Editar nombre/cantidad → Guardado
```

| Step | Actor                 | Action                                                                 | Result                                                             |

## Main journey: Reiniciar la compra semanal

Quien hace la compra semanal desmarca de una vez todo lo comprado para repetir la compra sin borrar y recrear ítems.

```text
Abrir lista con ítems comprados → Menú de opciones → "Reiniciar compras"
        → Ítems desmarcados + total recalculado + aviso "Deshacer" (5 s)
```

| ---- | ---------------------------- | -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 1    | Quien hace la compra semanal | Pide reiniciar las compras de la lista | El sistema desmarca de inmediato, sin confirmación, todos los ítems comprados, sin alterar su nombre, cantidad ni precio |

## Main journey: General journey

Acciones sobre la lista y la navegación que no pertenecen a una historia de usuario concreta.

```text
Abrir lista → Renombrar | Limpiar comprados | Eliminar lista | Quitar de "Mis listas" | Volver al home
```

| Step | Actor                 | Action                                                  | Result                                                                                        |
| ---- | --------------------- | ------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| 1    | Quien tiene el enlace | Cambia el nombre de la lista                            | El sistema guarda el nuevo nombre conservando el mismo enlace                                 |
| 2    | Quien tiene el enlace | Usa "limpiar comprados" y confirma                      | El sistema elimina de una pasada los ítems que constan como comprados                         |
| 3    | Quien tiene el enlace | Solicita eliminar la lista y confirma                   | El sistema borra la lista con todos sus ítems; todo acceso posterior responde "no encontrado" |
| 4    | Usuario               | Quita una lista de "Mis listas"                         | La entrada desaparece del acceso directo                                                      |
| 5    | Usuario               | Usa el enlace de vuelta al home desde una lista abierta | Llega al home, donde vive "Mis listas"                                                        |

Applies to every journey:

- Nadie ve ni usa pantallas de usuario, contraseña o registro.
- No hay límite de personas ni de dispositivos que usen el enlace de una lista.
- Los nombres, cantidades y "quién agrega" se muestran siempre como texto, nunca como HTML.
- No existe pantalla ni búsqueda que enumere listas; solo se llega a una por su enlace.
- Las acciones nuevas (reiniciar, duplicar y copiar como texto) viven en el menú de opciones de la lista.
- Los importes se muestran con coma como separador decimal y separador de miles, y el símbolo de la moneda aparece en el encabezado y el total, no en cada fila.

## Alternative paths

- Nombre de lista vacío o de más de 60 caracteres tras recortar — la creación (y el renombrado) se rechaza con un error de validación.
- Nombre de ítem vacío o de más de 100 caracteres — la operación se rechaza con un error de validación.
- Lista con 200 ítems activos — el alta que la dejaría en 201 se rechaza con aviso de que se alcanzó el límite; marcar, editar y eliminar siguen disponibles, y "limpiar comprados" libera cupo.
- Navegador sin hoja de compartir nativa — la URL se copia al portapapeles con aviso; si tampoco puede copiar, se muestra la URL en claro.
- Hoja de compartir cancelada por el usuario — no se trata como error ni se muestra aviso.
- "Limpiar comprados" sin ítems comprados — no cambia nada y responde con éxito.
- Precio no numérico, negativo, con más de 2 decimales o fuera del máximo — la operación se rechaza con un error de validación; `12,50` y `12.50` son el mismo monto.
- Precio borrado — el ítem queda sin precio, no con cero.
- Ningún ítem no comprado tiene precio — no se muestra el total, pero las filas conservan su precio.
- Moneda vacía tras recortar o de más de 5 caracteres — el cambio se rechaza con un error de validación.
- Deshacer la eliminación de un ítem — se vuelve a crear con su nombre, cantidad, quién lo agregó, estado de comprado y precio.
- Ítem editado o marcado en un dispositivo y eliminado en otro — prevalece la eliminación.
- Dos personas modifican el mismo ítem casi a la vez — prevalece, campo por campo, el último valor recibido, sin aviso de conflicto.
- Edición de precio o de cantidad en curso mientras llega una sincronización — no se pisa el valor que el usuario está escribiendo.
- "Reiniciar compras" cuando la lista no tiene ítems comprados — la acción no se muestra.
- Duplicar y se excede el límite de creación de listas — la duplicación se rechaza y se muestra "Creaste demasiadas listas seguidas. Inténtalo de nuevo en N min." según el tiempo restante.
- Duplicar una lista que no existe (borrada o enlace inexistente) — "no encontrado", igual que ante cualquier otra lista inexistente.
- Navegador sin permiso de portapapeles al copiar como texto — el texto se muestra en un campo seleccionable para copiarlo a mano.
- Deshacer un reinicio tras un cambio de otro dispositivo — solo se vuelven a marcar los ítems que siguen existiendo y desmarcados; uno borrado o vuelto a marcar por otro no se toca.

## Error and empty states

- Lista sin ítems — se muestra un estado vacío que invita a agregar el primer ítem.
- Enlace que no corresponde a ninguna lista (mal copiado, con mayúsculas cambiadas, puntuación pegada o eliminada) — "no encontrado", sin indicar si la lista existió. Se ve una página 404 propia en español ("Página no encontrada") con el enlace "← Mis listas" del layout; el texto es idéntico exista o no la lista.
- Lista eliminada desde otro dispositivo mientras está abierta — en el siguiente sondeo (unos segundos) el cliente detiene la sincronización, la quita de "Mis listas" y muestra el aviso "Esta lista ya no existe." más "Quitada de tus listas en este dispositivo.". La vista queda con los últimos datos conocidos y el formulario de alta visible; la única salida es el enlace "← Mis listas".
- Se abre una lista guardada en "Mis listas" que devuelve "no encontrado" — la entrada se retira de "Mis listas".
- Escritura contra una lista ya eliminada (renombrar, agregar ítem, marcar, reiniciar compras) — se trata igual que una lista eliminada desde otro dispositivo.
- Sin conexión con la última vista conocida — se sigue mostrando la lista; las escrituras fallan con aviso y no se encolan; la sincronización se reanuda al recuperar la conexión.
- Primera carga sin conexión y sin caché del service worker — se muestra una página offline mínima.
- Alta repetida tras un corte de red — puede crear un ítem duplicado; se acepta.
- Ítem sin cantidad, sin precio o sin "quién agregó" — la fila no muestra marcador ni espacio en su lugar.
- Navegador sin hoja de compartir ni portapapeles — se muestra la URL en claro para copiar a mano.
- Reiniciar dos veces seguidas — la segunda no cambia nada.
- Recargar la página durante la ventana de deshacer — el "Deshacer" se pierde.
- Dos avisos de deshacer a la vez (borrar un ítem durante la ventana del reinicio) — el último reemplaza al anterior, que deja de poder deshacerse.
- Reiniciar o duplicar sin conexión — fallan con el aviso de desconexión existente, sin cola de escrituras; copiar como texto funciona sin red.
- Duplicar una lista vacía — crea una lista nueva sin ítems, con nombre y moneda.
- Duplicar una lista de más de 200 ítems — se copian todos.
- Doble envío de la duplicación — crea dos listas distintas, y cada una consume cupo de creación.
- Copiar como texto con comillas, emojis o saltos de línea en un nombre — el texto sale tal cual, un ítem por línea (el salto de línea se reemplaza por un espacio).
- Copiar como texto una lista vacía — copia solo el nombre y no ofrece total.
- Más de 20 listas abiertas — se descarta la más antigua de "Mis listas".
- Demasiadas peticiones desde una IP — el servidor responde 429. En una escritura (p. ej. agregar un ítem) el usuario ve "Demasiadas acciones seguidas. Espera N s e inténtalo de nuevo." (N sale de `Retry-After`) y el texto escrito se conserva; al crear una lista desde el home o al duplicar una, "Creaste demasiadas listas seguidas. Inténtalo de nuevo en N min.". En la sincronización automática el cliente ignora el error en silencio: no hay aviso y se mantiene la última vista conocida.

## Screens or views

- Home — acceso a crear una lista y a "Mis listas"; se llega abriendo la app o desde el enlace de vuelta en una lista; lleva a la vista de una lista.
- Vista de lista — muestra la lista con sus ítems, el total pendiente, la moneda, y las acciones de agregar, editar, marcar, compartir, renombrar, limpiar comprados, reiniciar compras, duplicar, copiar como texto y eliminar; se llega por el enlace público de la lista o desde "Mis listas"; lleva de vuelta al home.
- Página offline — interfaz mínima cuando la app nunca se abrió con conexión; se llega al abrir la app sin conexión y sin caché; no lleva a otra pantalla: es una página estática con el título "Sin conexión", un texto y un enlace "Reintentar" que recarga la URL pedida (sin JS).
